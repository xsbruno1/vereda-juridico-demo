# Verificação dos modelos e módulos

Execute `node tests/run.cjs` a partir da pasta `relax-studios`.
Não requer instalar dependências nem acessar a internet.

As verificações cobrem datas, lembretes, separação dos roteiros, preços, conflitos de agenda, período de temporada, importação conservadora de iCal, revisão administrativa de anúncios, escalas noturnas, ausências, exportação e acesso por link ao Meet. Os testes dos eventos usam os scripts reais com uma estrutura mínima de página.

Os dados são fictícios. Os testes não certificam conformidade jurídica, acessibilidade integral ou segurança de operação em nuvem. Navegação, contraste, responsividade, impressão e publicação precisam de conferência adicional. Esta pasta fica fora de `dist` e não é servida pelo site.
